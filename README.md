# Haulatik Portfolio

Интерактивное портфолио Хаулат Шидаковой.

## Что уже реализовано

- серо-графитовый editorial hero по композиции титульника портфолио;
- цветное фото без grayscale-фильтра;
- блоки 3+ / 70+ / Самозанятость на первом экране;
- stacked-scroll проекты: следующий проект наслаивается на предыдущий;
- раскрытие кейса в той же странице через нижний drawer;
- GIF-анимации внутри сайта;
- русские тексты;
- адаптивная мобильная версия;
- контактная форма с mailto fallback.
